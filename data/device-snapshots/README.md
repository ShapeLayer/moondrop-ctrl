# Reference register dump

`original-2026-09-27.json` holds raw HID read responses captured from one MOONDROP CHU II DSP before any EQ change. It is kept as a reference for the register protocol (report layout, EQ switch value, band encoding) and as test material for anyone writing a profile.

It is **not** a factory preset for every unit. The app and CLI capture each user's own "Original" snapshot automatically the first time a model is connected (see *Data folder* in the main README).
